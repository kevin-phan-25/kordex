# Shared API contracts

Go module kordex.local/api contains signed agent and maintenance protocols, the key generator and operations/v1alpha1 CRD types. OpenAPI is openapi/v1.json, pre-release 0.3.0 with 21 operations. CRDs and deep-copy code are generated with controller-gen v0.23.0. Runtime protocol remains v1. The private operations.kordex.local group is a pilot identifier pending public domain/conversion decisions.
